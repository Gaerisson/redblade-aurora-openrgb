# Fn shortcut focus implementation plan

**Goal:** While Fn is held in RedBlade+ Full, light only its existing shortcut keys and Fn; restore the normal host/local frame on release.

**Requested behavior:** Unassigned Fn positions are black even with fresh host RGB, reactive trails, lock-state fallback or an arbitrary Turbo target. Existing shortcut colors, Recorder/Windows status and Fn status remain. RGB Off, zero brightness and USB suspension remain authoritative. The overlay follows the shipped 33-position Full shortcut map, as existing shortcut colors do; no new shortcuts are added.

**Approach:** A 14-byte flash bitmap filters each existing eight-LED rendering chunk before status overlays. It adds no persistent RAM, EEPROM traffic, timer or HID work. Cover the bitmap against the published shortcut map and exercise actual RGB rendering. OpenRGB Core remains minimal, without Full's overlay; both editions receive the 0.8.2 version metadata for the release.

**Alternatives considered:** Clearing the host color buffer would lose the pre-Fn image. Reading VIA EEPROM for every LED would add unnecessary work. The existing fixed-position hint design permits a flash-only mask.

1. Add regression coverage to `tests/rendering_test.c` for all shortcut/non-shortcut LEDs, chunk boundaries, host restoration, local lock fallback, arbitrary Turbo and RGB Off; observe RED.
2. Add the flash bitmap and early black overlay to `firmware/aurora_via/redblade_controls.c`. Add a visible hint for Fn + Pause (media Stop). Check the bitmap against `fn-shortcuts.json`/`led-map.json` in the existing map validator; observe GREEN with all existing suites.
3. Update Full/Core version metadata, English/French guides, shortcut visuals, changelog and manifests. Build both ARM artifacts and the native benchmark; verify SRAM/stack/timer/USB settings and BIN provenance. Run Python, PowerShell and all eight C suites.
4. Obtain a fresh code review, commit/publish source, verify CI, and publish the two BINs plus complete sources as release 0.8.2 with verified checksums.
5. Prepare a private VIA backup and request the physical bootloader shortcut only when the update is ready. Flash Full after the owner's physical confirmation; verify programming, restore RGB and request a visible Fn check. Core remains build/host-tested unless separately installed.

Feature ideas are suggestions only, outside this implementation.
